# Bounded prefix byte-producing stage

`FN-EGA-000205`, `06C9:[7C16,7D5E)`, is recovered as [C17](../../src/recovered/td2ega_prefix_stage.c) with an [explicit byte-view API](../../src/recovered/td2ega_prefix_stage.h). [Build evidence](evidence/td2ega-prefix-stage-build-v1.json) and [797 original-instruction comparisons](evidence/td2ega-prefix-stage-validation-v1.json) establish a bounded raw stage, with534,154 synthetic output bytes compared. No supplied resource, full file format, corpus, real I/O or gameplay has been accepted.

The original takes source and destination offset/segment pairs plus an extra allocation word. It reads a24-bit declared count at source bytes1..3 and a depth/delta byte at4. It builds offset/threshold tables in CS7AD6/7AF6 and copies symbols into CS7B16. Valid native contracts bound these to16 rows and256 symbols, require every selected code to resolve within initialized tables, and require nonwrapping physical ranges. Source byte0 is not checked by this function; the surrounding dispatcher owns that check.

Input physical bits are consumed least-significant-bit first while code values grow left. Preserve16-bit offset/end arithmetic and the **last nonzero threshold** at empty depths, including an end threshold wrapping to0. The optional high-bit path accumulates decoded bytes modulo256 using the previous output byte. Tables are copied before output; source/output overlap then follows actual reads and writes. A fixture verifies unread input being overwritten by output without silently substituting an independent compressed-data copy.

The output counter has a significant boundary: a declared low word of0 writes **65,536 extra bytes**, while AX/DX still return the declared24-bit count. Declared0 writes65,536; declared65,536 writes131,072. Four isolated fixtures verify the effect with delta on/off and segment crossings. The native result separates `reported_bytes` and `written_bytes`. An importer or allocator cannot safely treat the return value alone as the number of bytes written. Actual resource validity and caller allocation safety remain open.

Original DS/SI/DI/BP/SS are restored, ES advances at destination offset wrap, DF returns clear, and the caller removes ten argument bytes after RETF. Source-stream wrap advances DS by1000h; source offset plus header/count/symbol bytes must be strictly below65,536 so the prefix copy does not wrap SI before stream normalization begins. Local C tables replace shared CS scratch only under a serialized, nonreentrant contract; original callback/scratch lifetime is not accepted by these vectors.

Checks include every byte value with delta on/off, fixed and mixed code depths,256 symbols,16-bit threshold wrap,256 varied streams, source/destination64KiB crossings, low-word-zero counts, in-place aliasing, whole bytes/guards, consumption, scratch/code boundaries, arguments/registers and far return. Eight native bounds/short-input diagnostics are outside original error equivalence and may follow partial output. No unbounded original error path is represented as a safe successful decode.

## Composition with the packed loader

[Forty-eight additional composition cases](evidence/td2ega-packed-loader-composition-v1.json) execute the actual `6D50`, cache/acquisition, allocation, raw reader, copy helpers, `7C16` and `6B02`. Only file-size/header helpers and DOS open/read/close services are synthetic. One-pass `6B02` fixtures return AX=0/DX=destination. Two-pass `7C16 → 6B02` fixtures return an intermediate byte count, move rounded paragraphs, then return the final far resource pointer. This explains a valid interface composition; it does not admit arbitrary stage orders or the entire supplied resource grammar.

Those cases also preserve the uncached SI/DI pop shift previously found with mocked callees. They establish that `6B02`'s initial header copy into stack locals requires DS=SS on this path. A later [bounded run/block C contract](td2ega-run-stage.md) covers6B02 and its two shared-frame near helpers under explicit marker/pool preconditions. The earlier sixteen all-callee-mocked ABI cases remain separate evidence. All actual caller data/allocation domains, wrapper orders/error/wrap paths, caller liveness and corpus validation remain open. Full resource decoding is still a later phase.
