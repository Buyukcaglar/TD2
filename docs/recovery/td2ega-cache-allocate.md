# Recovered cache allocation prefix

`FN-EGA-000182`, `06C9:[70A3,7147)`, has a reviewed metadata contract through either its normal far return or its call to external fatal handler `16A7:0002`. The [C17 implementation](../../src/recovered/td2ega_cache_allocate.c) and [header](../../src/recovered/td2ega_cache_allocate.h) compile with the pinned compiler. [Build evidence](evidence/td2ega-cache-allocate-build-v1.json) and [73,654 original-prefix comparisons](evidence/td2ega-cache-allocate-validation-v1.json) pin identities and scope. Full caller ownership and external failure cleanup remain open.

The original consumes a near filename and a paragraph count. It derives the new segment from the active top's segment plus size, advances the active descriptor, copies **twelve bytes from the basename**, including bytes after a terminator, and stores size/segment/status2. Native names therefore supply twelve readable bytes at the basename as well as a nonwrapping terminator. Names, mutable arena, output word and the original active stack frame must be disjoint and stable during the operation.

There are fifty descriptors, including sentinels0/49. If the new active row meets the first cached row, the routine advances the cache boundary once without explicitly clearing that skipped status. Segment overlap then clears cached statuses while advancing the boundary. All segment additions and comparisons preserve unsigned16-bit effects. A wrapped sum is an instruction effect, not evidence that the resulting physical allocation is safe or that a native host should allocate that address.

Normal return is AX=0, DX=allocated segment, with SI/DI/BP and segment registers preserved. The original caller removes four argument bytes after RETF. The native API exposes a separate event and writes the output segment only on success; resource offset0 remains valid.

Descriptor exhaustion reaches the fatal call before changing the arena. Segment exhaustion reaches a different fatal message **after partial allocation/eviction changes**. The native event preserves those prefix mutations. Tests stop before the first external handler instruction, so no mock return, rollback, DOS cleanup or termination result is admitted. Static review shows that the handler requests input/timer cleanup, formatting and runtime exit; exit eventually reaches DOS INT21/AH4C if its prior hooks return and DOS follows its termination contract.

Vectors include all7,350 descriptor-boundary/request combinations, every65,536 request word on a fixed empty arena, all256 name byte values and512 varied segment-edge arenas. They compare the whole synthetic DS64KiB, caller argument words, native name guards, success return/frame/registers and both fatal-call argument pairs. Results:31,205 normal returns,10 descriptor failures and42,439 segment failures;15,225,120 original instructions. Three native invalid-input diagnostics are outside original equivalence. No original resource payload, real file I/O, codec, renderer, audio, game session or complete cache lifetime was exercised.
