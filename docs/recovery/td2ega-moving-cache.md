# Paragraph moves and cached-side compaction

Three additional C17 contracts have compiled and passed isolated original-instruction comparisons: `FN-EGA-000179` at `06C9:6FE8`, `FN-EGA-000180` at `7030` and `FN-EGA-000183` at `7147`. These support the ongoing P1-05 ownership review. Every actual caller's range/exclusion preconditions and complete cache lifetime remain open.

The [paragraph-copy C](../../src/recovered/td2ega_paragraph_copy.c) maps admitted source/destination segments to an explicit external byte pool. It preserves ascending or descending word order, including overlap cases in which that order repeats source data. Neither operation automatically chooses a safer direction. The original functions use chunks of at most1000h paragraphs/8000h words; under nonwrapping pool preconditions their linear word sequence is equivalent to the C loop. Native out-of-range diagnostics are separate from original register results.

[Copy build evidence](evidence/td2ega-paragraph-copy-build-v2.json) and [220 comparisons](evidence/td2ega-paragraph-copy-validation-v2.json) cover both directions, zero counts, 64KiB boundaries, multiple chunks, identical spans, both overlap directions, varied lengths/positions and the final physical paragraph. Whole576KiB synthetic pools and guards are compared, with separate sixteen-byte edge fixtures. Original DS/SI/DI/BP/DX restoration, AX/ES chunk effects, BX/CX, far frames and DF=0 are checked. The C implementation uses byte reads/writes and fixed-width arithmetic rather than file overlays or host alignment assumptions. A native pool-length overflow guard was corrected before accepted validation; the earlier private source/build remains historical.

The [compactor C](../../src/recovered/td2ega_cache_compact.c) visits sentinel49 first, scans cached rows backward and retains **status bit0**, rather than assuming only status1 is valid. It accumulates nonretained paragraph sizes modulo65536. When that accumulator is nonzero, it shifts retained metadata, clears the source status, copies twelve name bytes and moves payload through the recovered backward-copy helper. It updates the cached boundary, while stale metadata outside it remains observable. The accumulator is not reset after a move.

[Compaction build evidence](evidence/td2ega-cache-compact-build-v1.json) and [1,833 comparisons](evidence/td2ega-cache-compact-validation-v1.json) execute original7147 and actual7030 instructions: **9,565 real helper calls**, with no mocked payload moves. Cases cover all1,024 ten-row hole masks, every cache boundary with six status values, 512 varied size/status snapshots, a zero-sized retained move and a move crossing64KiB. Each comparison checks DS64KiB, a synthetic128KiB pool with guards, far return and preserved registers. Original ES and DF change only if the move helper is called; a zero-sized call still clears DF.

The native compactor requires a stable exclusively owned fifty-row arena, active top below cached first, an odd-status size0 right sentinel and valid nonwrapping generated moves. Bounds diagnostics are outside original equivalence and can follow partial metadata mutation; they do not promise rollback. No resource format, real media, DOS service, complete caller lifetime, game session, rendering, audio or fidelity gate is established by these tests.

## Acquisition and the two release policies

`FN-EGA-000184`, `71B4`, now has a [C acquisition contract](../../src/recovered/td2ega_cache_acquire.c), [build record](evidence/td2ega-cache-acquire-build-v1.json) and [3,510 comparisons](evidence/td2ega-cache-acquire-validation-v2.json). These execute the actual basename, forward-copy, compactor and backward-copy instructions. There are1,798 hit paths with1,798 forward and5,109 backward moves, plus1,712 misses. Whole descriptors and payloads agree. It captures the source segment before overwriting the descriptor, and supports the valid alias in which the new active descriptor is the matched cached row.

A matching right sentinel is outside this admitted resource domain: the original can consume or damage its sentinel/boundary. Native diagnostic rejection of that input is explicit and has no original-equivalence claim. Every actual filename/descriptor-space caller must establish that precondition before core integration.

`FN-EGA-000186` (`72C6`) and `FN-EGA-000187` (`736B`) are translated together in [release C](../../src/recovered/td2ega_cache_release.c). [Build evidence](evidence/td2ega-cache-release-build-v1.json) and [8,184 prefix comparisons](evidence/td2ega-cache-release-validation-v1.json) execute the actual forward/backward copy helpers. Both search by segment, including free interior rows, choose the highest duplicate, update the argument segment word and trim a released top over free predecessors. Unknown segments stop at the external fatal call without executing cleanup.

The fast policy checks gap before the cache with **gap >= size** and may return the new cached segment in DX. The shifting policy checks gap to the end sentinel with **gap > size**, can move cached rows toward lower segments, and always returns DX=0 even when it caches the released block. Both return the original offset in AX. Replacing them by one release operation or treating any returned AX as a complete pointer would lose behavior.

An additional descriptor alias is preserved: slow-release instruction `7451` writes the destination segment before `7455` reads the source segment. Releasing row48 into an empty cache aliases source and destination descriptors, so the original backward helper receives identical source/destination segments and does an identity copy at the new location. The synthetic fixture verifies unchanged payload bytes for that path; the C keeps the late read. This is an observed instruction effect, not acceptance of the path's long-term ownership or historical intent. Interior releases without a spare descriptor can also overwrite active-top metadata. Actual caller exclusion/invariants remain required.

Checks include all active/cache boundary pairs, top/interior/unknown requests, free-row trims, exact-gap equality, duplicate segments, the row48 alias, whole DS/payload/guards, updated arguments, conditional ES and DF. Native diagnostics and external fatal cleanup remain distinct from these original-prefix comparisons.
