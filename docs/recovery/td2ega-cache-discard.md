# Recovered cache discard prefix

`FN-EGA-000188`, `06C9:[7490,74D4)`, is translated to [C17](../../src/recovered/td2ega_cache_discard.c) with a [bounded metadata API](../../src/recovered/td2ega_cache_discard.h). [Build evidence](evidence/td2ega-cache-discard-build-v1.json) and [69,209 isolated comparisons](evidence/td2ega-cache-discard-validation-v1.json) establish normal return or the call boundary before external fatal handler `16A7:0002`. Full caller lifetime and fatal cleanup remain open.

The original receives an offset/segment pair but ignores the offset. It searches downward from the active top, excludes the left sentinel, and selects the highest matching segment. It does **not** test status before matching: a free interior descriptor with that segment can still be found. It clears the selected status, and only a match at the top trims preceding free rows. The left sentinel must have nonzero status to bound that trim.

Normal return leaves AX equal to the supplied segment, preserves DX/SI/DI/BP and segment registers, and leaves DF unchanged. The caller removes four argument bytes after RETF. No payload is moved, no cached descriptor is created, and no far storage pointer is returned. The native API exposes success or an unknown-segment event rather than assigning meaning to AX that the original does not have.

Unknown segments reach the original fatal call with message `65A5` and the segment argument before metadata changes. The harness stops there; it does not execute or mock cleanup. Tests compare the whole synthetic DS64KiB, all caller argument words, normal return/registers and unchanged DF. They cover every active/target row pair, all runs of free predecessors, duplicate segments, matching free rows and every 16-bit segment request on a fixed three-row arena. Results: 2,402 normal returns, 66,807 unknown-segment events and 2,318,638 original instructions. Two native invalid-input diagnostics are outside original equivalence. No resource payload, DOS, codec, gameplay, rendering or audio was exercised.
