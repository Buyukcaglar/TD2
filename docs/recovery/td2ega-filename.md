# Recovered DOS basename helper

`FN-EGA-000181`, original `06C9:[7083,70A3)`, is a 32-byte filename helper. Its instruction contract is explained, translated to C17, compiled and compared with isolated original instructions for **1,835 synthetic vectors**. This accepts the bounded helper contract, not a filesystem, resource codec or game core.

Source: [td2ega_filename.c](../../src/recovered/td2ega_filename.c) and [header](../../src/recovered/td2ega_filename.h). [Compilation evidence](evidence/td2ega-filename-build-v1.json) pins MSVC19.44, C17 `/W4 /WX /O2`, source/recipe and private DLL/object hashes. [Differential evidence](evidence/td2ega-filename-validation-v2.json) records 2,561,665 original helper instructions, guard and guest-register checks. No original filename or media payload is embedded in the C implementation.

The original accepts one near filename offset through SS:BP+6, with DS selecting the bytes. It scans forward to the first null, remembers the byte after each colon or backslash, and returns the final near position in AX. It does not case-fold, trim quotes/spaces or treat a forward slash as a separator. A trailing separator returns the position of the null byte. An offset-zero result is valid. The callee updates its argument-copy stack word, preserves SI/BP and other general/segment registers apart from AX, and uses RETF with caller cleanup of the two-byte argument.

CLD clears DF. The terminating OR AL,AL gives CF=OF=0, ZF=PF=1 and SF=0; AF is undefined and excluded from comparison. The C API exposes a relative byte offset and explicit success status instead of a segmented pointer or CPU flags. For a supported nonwrapping input at original offset `start`, the mapping is `original AX = start + native relative_offset`.

The admitted input domain is a readable, null-terminated byte span contained within one nonwrapping16-bit range. The original filename span is disjoint from the active stack frame/argument-copy writes; the native input span and output word are also disjoint. Tests cover every byte value in three contexts, separator positions0..255, 512 seeded varied paths, empty names, embedded terminators, several original starting offsets including zero, and full64KiB spans ending at offset65535. Guest checks include the far frame, argument-copy update, preserved registers/segments, defined flags and unchanged input/guard bytes.

Three native-only cases validate explicit diagnostics for a missing terminator, an empty readable span and an oversized span. These diagnostics have no original-equivalence claim outside the admitted domain; the original unbounded scan can wrap or continue indefinitely there. No second compiler/host, actual DOS filesystem, full resource parser, Windows host, gameplay or fidelity acceptance is established.
